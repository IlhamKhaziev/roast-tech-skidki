Слайд 03 • Физический Фундамент

Закон Электромагнитной Индукции

Слайд 03/06

В основе технологии лежит открытие Майкла Фарадея (1831 г.): переменное магнитное поле наводит вихревое электрическое поле в замкнутом проводнике.

1

1. Генерация Тока (Tx)

Высокочастотный ток (110–205 кГц) подается на катушку передатчика, создавая быстро меняющееся поле.

I (AC) ➔ B(t)
2

2. Магнитный Поток

Линии магнитного поля пронизывают витки катушки-приёмника внутри смартфона через зазор 5–8 мм.

Ф = ∫ B · dS
3

3. Наведение ЭДС (Rx)

Изменение потока наводит ток в приемнике. Выпрямитель превращает его в постоянный ток (DC) для АКБ.

ЭДС = -dФ / dt
Закон Фарадея-Ленца

ЭДС = - N · (ΔФ / Δt)

N: Число витков
ΔФ: Изменение потока
Δt: Время
